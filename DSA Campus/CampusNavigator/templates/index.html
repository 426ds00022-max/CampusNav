1. Graph Representation

The campus is modeled as an undirected graph using a Python dictionary (Adjacency List). Each location is a node, and each physical path is a two-way edge connecting them.

2. Breadth-First Search (BFS)

BFS uses a FIFO Queue (collections.deque) to explore the campus layer by layer. It is mathematically guaranteed to find the route with the fewest connections.

3. Visited Set Tracking

A Python set tracks all visited locations. This prevents infinite loops, prevents revisiting already explored buildings, and achieves an optimal O(V + E) time complexity.
